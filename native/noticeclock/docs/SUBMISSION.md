# Reviewer submission draft: Noticeclock

**Contribution category:** Standalone Intelligent Contract

**What it solves:** Enforce consent-bound notice/cure rules while GenLayer validators independently classify breach identification, applicability and cure specificity.

**Why GenLayer:** frozen contract terms need subjective evidence interpretation that deterministic code cannot express, while preventing the model from controlling actor authority, amounts or deadlines. Independent validators must reproduce the full small semantic fact vector; only after accepted consensus does deterministic contract logic update state.

**Reusable primitive:** a bounded schema version, frozen rule/evidence hashes, multi-party consent, independently validated comparative model decision, append-only dispute lineage, and explicit inconclusive state.

**Known limitations:** Understands text, does not prove off-chain delivery. Receipts are party-submitted, and a submitted document can be fabricated.
